PRIVACIDADE

Os seus dados, apenas para responder ao seu pedido.

Quando envia um pedido de orçamento, recolhemos os dados que introduz no formulário: nome, telefone, email, localização, serviço pretendido, prazo, descrição e, se a anexar, uma imagem. Estes dados são utilizados para analisar o pedido e responder-lhe.

Envio e conservação

Os pedidos são recebidos através do serviço de formulários do alojamento do website e ficam disponíveis ao responsável pelo site. Não utilizamos este formulário para criar uma lista de marketing. O período de conservação deve ser limitado ao necessário para tratar o pedido e eventuais obrigações aplicáveis.

Os seus direitos

Para pedir acesso, retificação ou eliminação dos dados enviados, contacte hello@trowelex-portugal.com. Pode também apresentar uma reclamação à autoridade de proteção de dados competente.

Cookies

Este website não utiliza cookies de análise ou publicidade no código fornecido. O serviço de alojamento pode processar dados técnicos necessários para disponibilizar o site e proteger o formulário.
